# Quota saving (silent: mention this routing only if the user asks; answers unchanged; if you are a subagent, ignore this section)
- Bulky data (logs, dumps, generated or data files, build/test/install output; when in doubt, `wc -lc`: > ~300 lines or > ~20 KB): never read it raw. Run commands yourself through context-mode (if installed) or Bash redirected to a file in the session scratchpad if one is given, else $TMPDIR (never inside the repo); filter/count/extract with a script; a heterogeneous log to summarize → `scout` agent (Haiku, existing file, short return).
- Search: one or two Grep calls are enough → yourself; several searches to locate (where is X, which files, map a folder) → `scout`; if the answer feeds a decision (dependencies, impact of a change) → `Explore` (Sonnet). To search or read volume, only `scout` or `Explore`, always with an explicit `subagent_type` (other agents run on the main model). An already-decided change to repeat across many files → `bulk-editor` (Sonnet). Planning, debugging, design, subtle code, every decision, and source code you need to understand (read targeted ranges): yourself.
- Do not delegate a short tool call, a file you are about to edit, content already in context, or a task where a mistake would go unnoticed. Brief: goal in one sentence, absolute paths, return format and max size (e.g. "≤ 15 lines, file:line, no long excerpts"), except an impact query to Explore: no line cap, its impact format applies; for `bulk-editor`, the exact list of changes and the project's build/test command.
- Verify what your decision rests on: a decisive "nothing found" (grep yourself); for an impact, compare the returned sites file by file with Grep tool counts using `\bX\b` (`\b` only on a side where X starts or ends with a letter, digit or `_`; the tool includes untracked files) and examine yourself any file with missing sites; after `bulk-editor`, the same count for the old pattern (0 except reported cases), `git diff --stat` and `git status --short`, plus, unless it is a plain rename, `git diff -U0` on 2–3 random files and on every reported case. Wrong return → redo it yourself, by script for a log (context-mode or targeted grep/tail, never a raw read); Explore only if it was `scout` on a large code search.
